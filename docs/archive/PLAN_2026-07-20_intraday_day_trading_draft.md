# 台股盤中 Day Trading 資料源擴充計畫（草稿，待使用者決定關鍵取捨）

## 背景
現行 `stock_tracker`（`C:\Users\william.chen\claude\stock_tracker\`，v2.1）已用 FinMind（免費匿名/300 req/hr）＋ yfinance ＋ TWSE 做盤後分析（Volume Profile + Order Flow delta + 均線量價評分）。使用者想擴充到台股**盤中即時** day trading，並確認美股（IBKR）、加密貨幣（Binance）端的免費選項。

## 研究結論摘要（完整報告見對話記錄，來源皆附官方文件 URL）

| 資料源 | 免費層能拿到什麼 | 盤中即時 tick/五檔 | 申請門檻 |
|---|---|---|---|
| FinMind | 日K、法人籌碼等盤後資料 | **不行**——tick/五檔快照官方文件明文僅限付費 Sponsor 會員 | 免費註冊即可（盤後用） |
| TWSE/TPEx OpenAPI | 日/月/年級歷史資料 | 不行（純盤後統計） | 免申請 |
| mis.twse.com.tw（非官方即時源，目前 v2.1 的 fallback 已有用到） | 約 5 秒延遲的即時報價、五檔 | 可以，但屬非公開端點，有隨時被擋 IP/改版風險 | 免申請 |
| **Shioaji（永豐金）** | tick、五檔皆可訂閱，流量依近30日成交金額分級 | **可以**，較穩定 | **需開永豐證券戶**＋臨櫃簽約 |
| **Fugle MarketData** | 免費層 5 訂閱數/1連線/60次分鐘；逐筆/五檔 WebSocket 可用但額度小；完整日內快照/技術指標需開發者方案 NT$1,499/月起 | 免費層小規模可用，正式用建議付費 | 只需註冊富果會員即可申請（不需新開證券戶） |
| 凱基證券 | 下單導向，非資料分析用 API | 不適合 | 需開戶 |
| IBKR | 15-20分鐘延遲行情免費 | 即時需另訂閱市場數據包（月費） | 需 IBKR 帳戶（已有） |
| Binance | 完全免費、免帳戶，REST/WebSocket 皆可拿即時逐筆/K線/訂單簿 | 可以，最完整 | 無需申請 |
